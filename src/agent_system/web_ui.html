連線與模型

角色

只寫「這個角色是誰」就好。講話長度、繁體中文、輸出格式那些規則在下面的 System prompt 裡，所以角色怎麼改都不會把 pipeline 弄壞。

長期記憶

每一輪都會被塞進 system prompt，所以寫「事實」比寫「故事」有效。 取消勾選＝暫時不用但留著。標著「範例」的兩條是內建的、預設關著， 勾起來再問一次同樣的問題，就看得出記憶怎麼影響回答（可以直接編輯或刪掉）。

短期記憶

        

      

      

        
        

          每次送出時會把最近這幾輪的一問一答一起帶上，模型才知道「它」「剛剛那個」在指什麼。
          超過的舊對話會自動被丟掉；設太大會變慢也比較花錢。
          按對話區的「清空歷史」就立刻忘光，角色與長期記憶不受影響。
        

      

    


    

      

        
工具

        

      

      

        

        

          關掉的工具不會出現在 prompt 裡，模型硬點也不會被執行。
          工具定義在 src/agent_system/tools.py 的 TOOL_SPECS／TOOL_FUNCS；
          「試跑」是直接呼叫函式，不經過 LLM，也不用金鑰。
          有輸入框的工具需要 query：對話時是模型自己把問句改寫成關鍵字或日期，
          回覆下方的工具標籤會顯示它實際送了什麼。搜尋走 DuckDuckGo（免金鑰），
          拿回來的是前幾筆的標題與摘要，不是網頁全文。
          行事曆存在本機的 src/agent_system/calendar.json，
          沒有連任何雲端服務，用文字編輯器就能打開看。

進階：角色、情緒、工具、記憶被塞進去的那張骨架。平常只要改上面的「角色」就夠了。

        

          展開編輯
          
          

            {role}、{memory}、{emotion_menu}、{tool_menu}
            送出前會自動代入。套用後下一輪生效，對話歷史不會被清掉。
          

          

            最後那段 {"say": ..., "emotion": ..., "tool": ...} 的輸出格式別刪：
            程式是照這三個欄位去取台詞、動作與工具的，格式跑掉就只會聽到「抱歉，我剛剛沒想到要說什麼」。
